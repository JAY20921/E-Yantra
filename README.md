## About This Project

This repository contains all the source code, hardware designs, and documentation for our team's entry into the e-Yantra Robotics Competition (eYRC) 2025-26. The project is centered around the **"MazeSolver Bot"** theme, which challenges us to design, build, and program an autonomous robot capable of navigating and solving complex mazes.

Our approach integrates hardware design using Verilog for FPGAs with embedded software to create an efficient and intelligent robotic system.

## Project Objectives

The primary goals of the MazeSolver Bot are to:
-   Autonomously navigate a given maze from a start point to a designated end point.
-   Implement efficient pathfinding algorithms to find the optimal route.
-   Utilize sensors for accurate wall detection and environment mapping.
-   Develop robust motor control for precise movement and turning.
-   Complete all tasks as specified in the eYRC rulebook.

## Technology Stack

-   **Hardware Description Language:** Verilog HDL
-   **Platform:** DE10-Lite FPGA Board (or specified hardware)
-   **Software:** C/C++ for embedded systems, Python for scripts/simulation
-   **Tools:** Quartus Prime, ModelSim, Git & GitHub

## Repository Structure

This repository is organized into tasks as laid out by the competition:
-   `Task-1A/`: Contains Verilog files for Frequency Scaling & PWM Generation.
-   `Task-1B/`: Will contain designs for Distance Measurement.
-   `docs/`: Includes datasheets, problem statements, and other documentation.
-   `sim/`: Holds simulation files and testbenches.
